About this experiment

I trained this controller by imitation: it learned from examples of swinging up and balancing. The controller reads the joint angles and velocities and applies torque at the elbow. The base joint has no motor.

The policy and simulation run in your browser. Some starting positions recover; others do not. There is no fallback controller.

The model uses 467 radial-basis units and limits torque to ±1 N·m. It chooses a new action every 50 milliseconds.
